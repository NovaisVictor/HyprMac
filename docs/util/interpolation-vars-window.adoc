%{window-id}:: Number. Window unique ID
%{window-id-native}:: Number. macOS native window ID (`CGWindowID`). Useful for integration with other tools that operate on native window IDs.
macOS native tabs are separate windows under the hood. HyprMac treats the whole tab group as a single window with a stable `%{window-id}`, but `%{window-id-native}` changes whenever another tab is brought to the front.
Different apps implement tabs differently. Apps that use native tabs: Finder.app, Terminal.app. Apps that don't use native tabs: Safari. Third-party apps usually don't use native tabs
%{window-title}:: String. Window title
%{window-is-fullscreen}:: Boolean. Is window in fullscreen by `hyprmac fullscreen` command
%{window-is-pinned}:: Boolean. Is window pinned by `hyprmac pin` command
%{window-is-pseudotiled}:: Boolean. Is window pseudotiled by `hyprmac pseudotile` command
%{window-layout}:: String. An alias for `%{window-parent-container-layout}`
%{window-parent-container-layout}:: String. The layout (`v_tiles`, `h_tiles`, `v_accordion`, `h_accordion`, `v_master`, `h_master`, `v_center_master`, `h_center_master`, `floating`) of the window's parent container.
