// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help

--stdin::
Capture CLIs stdin and forward it to `<hyprmac-shell-expr>`.
If not supplied, stdin is ignored.

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

<hyprmac-shell-expr>:: This argument is HyprMac's shell expression.
See https://github.com/NovaisVictor/HyprMac/blob/main/docs/guide.adoc#shell for more info.
