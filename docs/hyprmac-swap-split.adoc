// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

The command acts on the nearest tiling parent container of the window.
Each child keeps its size, so in a container with two children, the children swap their places and their sizes.

The command fails if the window isn't tiling, or if its parent container has `accordion` or `master` layout.
