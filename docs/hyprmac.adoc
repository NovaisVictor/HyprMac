== Synopsis
[verse]
hyprmac [-h|--help] [-v|--version] <subcommand> [<subcommand-options>...] [<subcommand-arguments>...]

== Description

HyprMac is an i3-like tiling window manager for macOS

*hyprmac* command line program is used to manipulate HyprMac and query its state.

See https://github.com/NovaisVictor/HyprMac/blob/main/docs/commands.adoc for available <subcommand> options

See each <subcommand> individual man page for <subcommand-options> and <subcommand-arguments>

== Options

-h, --help:: Print help
