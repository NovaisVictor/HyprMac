// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
hyprmac config [-h|--help] --get <name> [--json] [--keys]
hyprmac config [-h|--help] --major-keys
hyprmac config [-h|--help] --all-keys
hyprmac config [-h|--help] --config-path

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

For now, only the following config options are supported:
`mode.*`, `new-window-placement`, `master-ratio-percent`, `mouse-grab.*` and `animations.*`

Under the hood, the config is represented as recursive data structure of maps, arrays, strings, integers, floats, and booleans.

Printing without `--json` or `--keys` flag is supported only for scalar types (strings, integers, floats, and booleans) and array of scalar types.
Printing other complicated objects requires `--json` or `--keys` flag.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help
--get <name>:: Get the value for a given key. You can inspect available keys with `--major-keys` or `--all-keys`
--major-keys:: Print major keys
--all-keys:: Print all available keys recursively
--json:: Print result in JSON format
--keys:: Print keys of the complicated object (map or array)
--config-path:: Print absolute path to the loaded config

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* List all binding modes:
+
----
$ hyprmac config --get mode --keys
main
service
----
* List all key bindings for 'main' binding mode:
+
----
$ hyprmac config --get mode.main.binding --keys
alt-1
alt-2
...
----
* List all key bindings for 'main' binding mode in JSON format:
+
----
$ hyprmac config --get mode.main.binding --json
{
  "alt-w" : "workspace W",
  "alt-y" : "workspace Y",
  "alt-n" : "workspace N",
  "alt-shift-e" : "move-node-to-workspace E",
  "alt-shift-m" : "move-node-to-workspace M",
  "alt-shift-t" : "move-node-to-workspace T",
...
----

* Get the master ratio:
+
----
$ hyprmac config --get master-ratio-percent
55
----

* Get the root container layout of the per-workspace rule of workspace 'G':
+
----
$ hyprmac config --get workspace.G.default-root-container-layout
accordion
----
